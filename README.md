# 5213 项目自主评估网站

一个用于国际孵化器项目初筛的轻量网站。评审人员可以上传项目材料、填写项目评估表，并在点击“开始自主评估”后获得预估等级、Agent 建议和评估记录。

## 功能

- 黑白简洁界面，适合正式评审场景
- 文件上传状态提示：待上传、文件已读取、AI 正在解析
- 从文本类项目材料中尝试识别姓名、学历、专利、论文、产业方向等字段
- 自动填充字段会以灰底高亮，便于人工复核
- 出生年填写后自动计算年龄
- 硬性条件检查，包含团队人数、股权、萧山落地、产业方向等
- 点击按钮后才触发评估，不做实时等级变化
- 评估记录保存在浏览器本地，并支持查看详情
- 信息不完整时可导出补充信息报告

## 本地运行

```bash
npm run dev
```

然后打开：

```text
http://127.0.0.1:3000/
```

## 代码检查

```bash
npm run check
node --check public/app.js
```

## 当前评估逻辑

当前版本使用前端本地规则进行初筛：

- 持股低于 20% 判定为不符合
- 不能在萧山区缴纳社保时，申报人持股需超过 50%
- 团队总人数按“申报人 + 核心成员”计算，需不少于 3 人
- 除主申报人外，需两名核心团队成员全职并后期缴纳社保
- 未落地萧山或产业方向不符合时判定为不符合
- 博士、海外经历、专利、论文、项目阶段等会影响 A/B/C 预估等级
